Privacy policy

Last updated 22 October 2026

TripWish is an iOS travel-planning app currently in development. This policy describes the promotional website at nikog8.github.io/tripwish. Before the app is released, this page will be updated to cover what the app itself processes.

Who to contact

Email n3308371@gmail.com with privacy questions about this website or about TripWish.

This website

The site is a static set of pages. It does not ask you to create an account. It has no forms, comments, analytics, or advertising. Fonts are files on this site, not requests to a third-party font host.

Visiting the site does not require you to submit personal information. The pages are hosted on GitHub Pages. GitHub receives ordinary connection data, such as IP address and user agent, because GitHub operates the hosting network. That processing is covered by GitHub’s own terms and privacy policy.

This site does not set its own cookies and does not use tracking pixels.

Email

If you email n3308371@gmail.com, we receive the address you write from and whatever you put in the message. We use it to reply and to handle what you asked. We don’t sell that email or add it to a marketing list.

The app

TripWish is not on the App Store yet. There is no public app to install, and this website cannot book a trip.

Before release, this policy will describe the information the app processes — including trip wishes you type, plans the assistant generates, and any account or booking details — and the App Store listing will carry Apple’s privacy details.

Bookings

Stays and travel bookings via Booking.com. When booking is available in the app, Booking.com will process the information needed to complete a reservation under Booking.com’s own privacy policy. TripWish is an independent app. Booking.com does not operate this website, and TripWish is not endorsed by Booking.com.

Children

TripWish is a travel-planning product for adults. This website is not directed at children.

Changes

If this policy changes, the date at the top of the page changes with it. The current version is the one published here.
